# Examples and Code Implementations

This directory contains practical examples and code implementations for the CS25 Large Foundation Models course.

## Directory Structure

- `notebooks/` - Jupyter notebooks with interactive examples
- `scripts/` - Python scripts for various implementations
- `datasets/` - Sample datasets and data processing utilities

## Getting Started

1. **Prerequisites**: Ensure you have Python 3.8+ and the required packages installed
2. **Installation**: Install the required dependencies from `requirements.txt`
3. **Examples**: Start with the notebooks in the `notebooks/` directory

## Available Examples

*Examples will be added as the course progresses*

- Diffusion Models
- Flow Matching
- Variational Autoencoders
- Normalizing Flows
- Generative Adversarial Networks
- Autoregressive Models
- Reinforcement Learning for Foundation Models
