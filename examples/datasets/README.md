# Sample Datasets

This directory contains sample datasets and data processing utilities for the CS25 course examples.

## Available Datasets

*Datasets will be added as examples are developed*

### Planned Datasets
- **MNIST** - Handwritten digits for basic diffusion model training
- **CIFAR-10** - Natural images for more complex generative modeling
- **CelebA** - Face images for conditional generation
- **Text Data** - For autoregressive language modeling examples

## Data Processing Utilities

- Data loading and preprocessing scripts
- Data augmentation functions
- Dataset splitting utilities
- Data visualization tools

## Usage

1. Download datasets using the provided scripts
2. Preprocess data according to your model requirements
3. Use the data loaders in your training scripts
