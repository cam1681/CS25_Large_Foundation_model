# 📚 Lecture Materials

This directory contains all lecture materials for the CS25 Large Foundation Models course.

## Directory Structure

```
lectures/
├── source/                    # Source LaTeX files
│   ├── lecture0_introduction.tex
│   ├── lecture1_diffusion_model.tex
│   ├── lecture2_Flow_matching.tex
│   └── ...                    # All lecture source files
├── compiled/                  # Compiled materials
│   └── slides/                # PDF slides for each lecture
└── README.md                  # This file
```

## Contents

### Source Files (`source/`)
- `lecture0_introduction.tex` - Course introduction and overview
- `lecture1_diffusion_model.tex` - Diffusion Models
- `lecture2_Flow_matching.tex` - Flow Matching
- `lecture3_vae.tex` - Variational Autoencoders
- `lecture4_normalizing_flow.tex` - Normalizing Flows
- `lecture5_GANs.tex` - Generative Adversarial Networks
- `lecture6_autoregressive.tex` - Autoregressive Models
- `lecture7_discrete_diffusion.tex` - Discrete Diffusion
- `lecture8_world_model.tex` - World Models
- `lecture9_reinforcementlearning.tex` - Reinforcement Learning
- `lecture10_reasoning.tex` - Reasoning in Foundation Models
- `lecture11_agent.tex` - AI Agents
- `lecture12_ai4science.tex` - AI for Science

### Compiled Materials (`compiled/slides/`)
- PDF slides for each lecture
- Ready-to-use presentation materials

## Usage

1. **View Source**: Open the `.tex` files in `source/` to see the source material
2. **Ready-to-Use Slides**: Check `compiled/slides/` for ready-to-use PDF presentations
3. **Compilation**: Use LaTeX to compile individual lectures from `source/` if needed

## Prerequisites

- LaTeX distribution (TeX Live, MiKTeX, etc.)
- Required LaTeX packages (see individual files for dependencies)
